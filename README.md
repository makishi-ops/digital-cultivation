# 數位修真錄：天機城失控案（網頁版）

國中資訊科技「系統平臺」闖關課程，取自 KUSU 酷書的課程活動，內容和 KUSU 上的課程相同。

- 9 章、29 題、47 步，總分 100 分，建議分兩節課（序章～第三章、第四章～終章）。
- 故事用修真，操作用真電腦：小電腦模擬器、點選資料路線、CPU 分工、工作管理員、逐站測試網路、點出要查證的句子，以及系統日誌排事故鏈。
- 提示與訂正不扣分。

網頁版是純靜態網頁：

- 不用登入，沒有資料庫，也沒有伺服器程式。
- 進度只存在「這台電腦的這個瀏覽器」（localStorage）。換電腦、換瀏覽器、用無痕視窗或清除瀏覽資料，就會從頭開始。
- 上方的「重新開始」會清除這台電腦上的進度。

## 和 KUSU 課堂版的差別

| 項目 | KUSU 課堂版 | 網頁版 |
| --- | --- | --- |
| 故事、閱讀導引、題目、提示、判分、道印 | 有 | 相同 |
| 帳號登入、進度存在 SERVER、換電腦繼續 | 有 | 沒有 |
| 教師進度頁、CSV 匯出 | 有 | 沒有 |

## 在自己電腦預覽

網頁使用 JavaScript 模組，直接雙擊 `index.html` 會無法載入。在這個資料夾裡執行：

```bash
python -m http.server 8000
```

再打開 `http://localhost:8000/`。

## 檔案說明

| 檔案 | 用途 |

| `index.html`、`app.mjs` | 頁面外框與封面（取代 KUSU 的登入頁） |

| `lessons.mjs` | 每一關的閱讀導引與插圖說明 |
| `experience.mjs` | 閱讀與作答畫面 |
| `course.css`、`reading.css`、`compact.css`、`interact.css` | 課程樣式 |
| `preview.css` | 網頁版的封面按鈕 |
| `images/manifest.json` | 插圖清單；插圖完成前是空的，畫面顯示城景剪影 |
